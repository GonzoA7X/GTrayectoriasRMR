# Proyecto de Trayectorias RMR 
# 🤖 GTrayectoriasRMR

Una aplicación móvil nativa en Android diseñada para la generación de trayectorias y el control de robots móviles diferenciales mediante comunicación Bluetooth.

## 🚀 Características Principales

* **Conexión Inalámbrica:** Interfaz para buscar, emparejar y conectar el dispositivo móvil al módulo Bluetooth del robot.
* **Cálculo de Trayectorias:** Algoritmos integrados para procesar y enviar las coordenadas o comandos necesarios para el movimiento diferencial.
* **Interfaz Intuitiva:** Diseño centrado en facilitar la operación y el monitoreo de los comandos enviados en tiempo real.

## 🛠️ Tecnologías Utilizadas

* **Lenguaje de Programación:** Java
* **Entorno de Desarrollo:** Android Studio
* **Hardware/APIs:** Android Bluetooth API
